An end-to-end data science project utilizing **XGBoost** to iteratively predict individual powerlifting performance metrics (**Squat**, **Bench Press**, and **Deadlift**) based on a lifter's physical characteristics and their performance in the other two lifts.

This project follows the complete **Data Science Predictive Analytics Procedure**, taking a multi-million row global powerlifting database through rigorous cleaning, feature engineering, modeling, and evaluation.

---

## 📊 Dataset Overview

* **Source:** [OpenPowerlifting Database via Kaggle](https://www.kaggle.com/datasets/open-powerlifting/powerlifting-database)
* **Scope:** Pre-filtered dataset containing over 3 million raw historical lifting entries.
* **Features Used:** 
  * `SEX` (Engineered into binary `IS_MALE`)
  * `AGE` (Cleaned for data entry anomalies and filtered for valid competitor cohorts)
  * `WEIGHT` (Bodyweight in kilograms)
  * `SQUAT`, `BENCH`, `DEADLIFT` (Best competition 3-attempt lift scores in kg)

---

## 🔄 The Data Science Workflow

The Jupyter Notebook executes the following analytical pipeline:

1. **Data Collection & Preparation:** Loading the massive dataset efficiently, standardizing column naming conventions, and verifying initial memory constraints.
2. **Data Cleaning:** Handling missing demographic inputs, rectifying anomalous records (such as erroneous age entries under 8 years old), and filtering out ambiguous categorical values (`Mx`).
3. **Feature Engineering:** Creating numerical indicators, transforming categorical text variables into machine-learning-ready binary flags, and applying standard scalers (`StandardScaler`) where necessary.
4. **Exploratory Data Analysis (EDA) & Visualization:** Leveraging `Matplotlib` and `Seaborn` to inspect data distributions, evaluate age brackets, and understand physical correlations across weight classes.
5. **Predictive Modeling:** Iteratively training **3 distinct XGBoost regression models** to forecast each target lift independently from the remaining two attributes.
6. **Model Evaluation & Deployment Readiness:** Assessing prediction error metrics across all three models to ensure generalization before downstream deployment.
